# Kuzko EQ

EQ 6 bandes avec sidechain par bande (VST3, Windows). Chaque bande : Gain, Freq, Q,
puis SC (mode dynamique), Ext (detection sur l'entree sidechain), Thresh, Range.
Les bandes 1 et 6 sont des shelves, bouton Bell pour passer en cloche.

Compilation automatique : onglet Actions de GitHub, dossier Artifacts en bas de la page du build.
